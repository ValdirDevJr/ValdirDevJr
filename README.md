# Valdir Jr. 👋

Desenvolvedor Full Stack focado em construir aplicações web e mobile de ponta a ponta, com código tipado, segurança no servidor e rigor técnico.

Fundador do **[CVIP](https://www.cvipsaas.com.br)**, uma plataforma SaaS e Mobile desenvolvida para simplificar o cálculo da cascata tributária de importação e simular o impacto da Reforma Tributária 2027 (CBS/IBS).

---

### 🛠️ Stack que utilizo no dia a dia

- **Web:** Next.js (App Router), React, TypeScript, Tailwind CSS, Zustand
- **Mobile:** React Native, Expo, NativeWind, builds via EAS
- **Backend & Dados:** Supabase (PostgreSQL com RLS), Stripe API (webhooks), Vercel
- **Inteligência Artificial:** LangChain, Google Gemini API, OpenRouter (orquestração com fallback e validação de schema)
- **Testes & Automação:** Playwright, FFmpeg, Git

---

### 🚢 Projeto Principal: [CVIP SaaS & Mobile](https://github.com/ValdirDevJr/CVIP-PROJECT)

- **Problema real:** Ajudar importadores a saírem do cálculo amador em dólar e calcularem o custo real desembarcado com ICMS "por dentro" e taxas aduaneiras.
- **Transição fiscal:** Simulação lado a lado do modelo atual versus a Reforma Tributária (IVA Dual).
- **IA aplicada:** Sugestão de NCM por imagem ou descrição e análise cambial com conferência de schema.
- **Demonstração:** [cvipsaas.com.br](https://www.cvipsaas.com.br)
